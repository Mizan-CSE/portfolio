# Md Mijanur Rahman — Portfolio

Personal portfolio website for Md Mijanur Rahman, SQA Engineer.

🔗 **Live site:** https://mizan-cse.github.io/portfolio/

## Tech Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Framer Motion
- GitHub Pages (auto-deploy via GitHub Actions)

## Run locally
```bash
npm install
npm run dev
npm run build
```
